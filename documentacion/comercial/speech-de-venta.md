# Demostración comercial — Cancha Manager

## Presentación

“Tu complejo puede tener su propia web y recibir reservas sin tener que responder cada consulta de horario. El jugador elige cancha y turno, deja sus datos y obtiene un resumen para WhatsApp. Vos ves esa misma reserva en administración, revisás el comprobante y la confirmás.”

## Recorrido de la visita

1. Abrir la landing comercial y explicar el paquete: web personalizada, reservas y gestión.
2. Entrar a /demo. Aclarar que el complejo y los precios son ficticios.
3. Elegir fecha, cancha y horario. Mostrar el bloqueo temporal mientras se completan los datos.
4. Registrar una reserva en efectivo o adjuntar un comprobante de ejemplo. No transferir dinero.
5. Mostrar el código y el estado pendiente. Abrir el enlace de WhatsApp solo si el participante quiere enviar el mensaje al número del vendedor.
6. Abrir /admin/reservas con acceso privado. Buscar el código, revisar el archivo y confirmar.
7. Volver al resumen del jugador y mostrar el estado actualizado. Mostrar que el turno ya no se ofrece a otro grupo.
